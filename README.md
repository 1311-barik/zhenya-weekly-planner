# sheyn's planner — недельный планировщик

Персональный недельный планировщик (один пользователь). Сетка недели с блоками,
drag-and-drop, нормы, выходные, режим отъезда. Данные хранятся на сервере.

## Стек

- **Next.js 16** (App Router, фронт + API в одном приложении)
- **TypeScript + Tailwind v4**
- **SQLite + Prisma** — БД на сервере (`prisma/dev.db`)
- **Кастомный pointer-based drag/resize** — точное позиционирование по сетке (шаг 15 мин)
- Дизайн портирован из прототипа (тёплая «ателье»-палитра, Cormorant + Inter)

## Запуск (локально)

```bash
npm install
npx prisma db push       # создать БД по схеме
node prisma/seed.mjs     # засеять 7 стандартных блоков
npm run dev              # http://localhost:3000
```

## Авторизация (MVP)

Токен в `.env`:

- `AUTH_TOKEN=` пустой → доступ открыт (без фрикции, для локалки).
- `AUTH_TOKEN=секрет` → приложение требует ввод токена на `/login`
  (он кладётся в httpOnly-cookie).

## Что реализовано (Фаза 1, MVP)

- [x] Сетка недели Пн–Вс, шкала 6:00–23:00, блоки растягиваются по высоте
- [x] Библиотека стандартных блоков + авто-расстановка повторяющихся
      (Роберт/Инна — пятница); маркер «неделя засеяна» не возрождает удалённый повтор
- [x] Разовые блоки: клик по пустому месту или из библиотеки/inbox
- [x] Inbox (список задач) без привязки к дню
- [x] Drag-and-drop между днями/временем, resize за нижний край, шаг 15 мин,
      наложение блоков (раскладка по дорожкам)
- [x] Тогл выполнения (кружок), попап редактирования (название/время/длительность/цвет/удалить)
- [x] Нормы недели: 🧵 Ателье 2×4ч, 🏋️ Качалка 2×3ч — индикаторы в шапке
- [x] Выходной день (не более 1/нед, запрет добавления блоков, метка ВЫХОДНОЙ)
- [x] Режим отъезда «Я уезжаю / Я вернулась» (блоки ✈️, пропуск повторов)
- [x] Навигация недель ‹ ›, клик по дате → текущая неделя
- [x] Мобильный адаптив: один день + свайп-кнопки, inbox как bottom sheet
- [x] Хранение на сервере (SQLite), токен-авторизация

## Структура

```
prisma/schema.prisma   модель: Template, Block, Task, DayState, AwayPeriod, WeekSeed
prisma/seed.mjs        сид стандартных блоков
src/lib/               config (нормы/цвета/время), week (даты), store (бандл недели),
                       client (геометрия/API), auth, http, types
src/app/api/           route handlers: week, blocks, tasks, day-off, away, templates, login
src/components/        Planner (главный), EditBlockPopup, AwayPopup
```

## Деплой

Приложение самодостаточно (`next start`). На сервере:
`npm ci && npx prisma db push && node prisma/seed.mjs && npm run build && npm run start`.
Файл БД `prisma/dev.db` переживает рестарты; для бэкапа достаточно скопировать его.
